# Foundation depth, models, review and evaluation follow-up

This release progresses pending items 1–4. It does not complete publication-quality depth or bespoke simulations for all 354 lessons, independent scientific verification, or real learner trials.

- **Depth:** PB2.1 fluids, PB2.2 thermodynamics, MB2.2 conics and MB2.3 spatial geometry retain their existing theory and add extended derivations, assumptions and 24 distinct numeric transfer questions with hints/explanations. Eight earlier repeated warm-up/Core prompts were rewritten so each expanded bank has 12 unique prompts. The plane-rescaling question now specifies that both sides of the equation are rescaled.
- **Models:** Four embedded investigations add a draggable pressure probe, heat/work/energy comparison, focus-based ellipse traversal and point-to-plane projection. Sliders expose the same adjustable quantities to keyboard users. The existing gas-piston investigation remains available. Models show computed ideal quantities; they are not real laboratory data. Ellipse position does not advance uniformly in physical time; the plane drawing is a slice with different display scales, and the projected foot can leave that slice.
- **Review:** Internal scientific notes document what was checked and which sources still need inspection. A reproducible machine-readable and Markdown queue covers all 354 lessons. It flags 30 lessons with repeated prompts after four expanded banks were deduplicated and 332 without explicit widget declarations. These counts exclude inferred vector/black-hole widgets and two player-mapped mechanics models, and are not a claim that every explicit widget is bespoke or pedagogically complete. No independent reviewer or inspected exact source has been invented; all verification statuses remain pending.
- **Evaluation:** A voluntary pilot kit includes three four-question forms, participant handout generation, a human reasoning rubric and descriptive scoring. Reports retain attrition and assistance counts, expose per-item observations, separate unassisted totals and compare matched baseline/delayed participants. Numeric scoring cannot replace reasoning review. Forms have not been equated, and no learning-effectiveness claim is supported without real learner observations.

See [scientific notes](FOUNDATION-SCIENTIFIC-REVIEW.md), [review queue](COURSE-REVIEW-QUEUE.md) and [pilot instructions](FOUNDATION-LEARNER-PILOT.md). Independent review and real baseline/instruction/delayed sessions need willing people. Broad course expansion remains further authoring work; the four-lesson expansion should not be described as completing the full course.

Validation: the final production build/content validation passed for all 354 drafts; all 103 model/grading/evaluation tests passed; all 92 browser cases passed against the final build, including the complete 354-lesson rendering sweep and new keyboard/pointer interactions. The review queue was regenerated and git whitespace checks passed. No Firebase, Worker, provider or live deployment activation is part of this release.
