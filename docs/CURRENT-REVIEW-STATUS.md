## What remains external

Remaining source scopes and advanced-course depth are still open; this release does not claim equal richness or a new bespoke simulation for every one of the 354 lessons.

Use `npm run review:handoff -- NEW_DIRECTORY` for a fresh artifact-bound handoff, and the existing evidence gate before changing any lesson to verified/published. Revision guides are separately unapproved and included in review packets. Positive learner feedback and reported working sync/reminders do not substitute for scientific approval or scored learning evidence.
