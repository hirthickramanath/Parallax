# Mechanics unit: internal expansion and learner evaluation

PB1.1–PB1.4 now have 28 additional authored questions (24 numeric instances checked independently plus four conceptual transfer questions), hints, misconception explanations and deeper derivations. New collision and rolling models supplement the existing falling-body and pendulum explorations. All four remain drafts with exact source inspection and independent scientific review pending.

## Learning sequence to evaluate

1. Baseline: ask a novel force/acceleration, work/impulse, rolling-energy and pendulum-scaling question without showing solutions.
2. Predict: commit to an expected outcome for each model, including one changed assumption (drag, restitution, mass distribution or amplitude).
3. Manipulate: observe the predicted quantity, compare two cases and explain which governing equation accounts for the result.
4. Derive: retain the full equation, units, initial conditions and limiting case. Revealing text is not itself evidence of understanding.
5. Practise: use graduated questions and hints; an answer shown in feedback must be followed by a different independent transfer question before claiming successful remediation.
6. Revisit: use the scheduled recall interlude, then test transfer after approximately one week. Measure reasoning and retention, not just speed or XP.

Ask willing learners what was too easy, useful, difficult or unclear. The optional end-of-lesson feedback is stored with the learner's existing study records and can be exported. This is not passive tracking by an external analytics service. A learner's own progress export may contain personal notes; keep it private.

`node scripts/learning-report.mjs /path/to/parallax-progress.json` produces descriptive counts of first attempts, retries, tier outcomes and explicit difficulty feedback. It omits answer text and notes. It does not establish calibrated item difficulty, causation or effectiveness. First attempts are grouped by question and restart generation; prediction/theory-view events are excluded from answer accuracy.

For each lesson, review scientific correctness, diagram conventions, units, distractors, ambiguity, keyboard usability and whether a new-context problem can be solved without copying the worked example. Record actual reviewer/source evidence before a verification upgrade. Record sample size, prior knowledge, missing follow-ups and any assistance when interpreting learner outcomes.

No learner trial, physical experiment, capstone or independent source review is claimed to have been conducted by this implementation work. Expand the approach to other units only after reviewing what the observations support.
