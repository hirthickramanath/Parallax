<LessonSection id="story" title="Why this matters" layer="story">

Symbolic computation manipulates exact expressions and assumptions. It can expose a derivation or confirm an identity, but a returned formula still needs domains, branch conventions and physical interpretation.

</LessonSection>

<LessonSection id="intuition" title="Build the picture" layer="intuition">

The software follows the symbols and assumptions you provide. A parameter declared positive has different permissible simplifications from an unrestricted complex parameter.

</LessonSection>

<LessonSection id="concept" title="State the model" layer="concept">

A symbolic algebra system represents expressions exactly where possible, transforms them under assumptions, and separates symbolic operations from floating-point evaluation.

</LessonSection>

<LessonSection id="theory" title="Derive and qualify the result" layer="theory" fullOnly>

The identity $\sqrt{x^2}=|x|$ holds for real x; replacing it by x requires x≥0. Complex square roots and logarithms have branch conventions that can invalidate familiar real identities. Cancelling a factor from a rational expression preserves equality only where the original denominator was nonzero; simplification does not retroactively fill the original domain.

In SymPy, construct exact rational values before numerical evaluation. A binary float supplied first has already lost exact decimal or rational information. Keep symbolic parameters with declared assumptions, then use substitution and high-precision evaluation when needed. Verify dimensions separately: an algebra package does not automatically know that adding a distance to a time is physically meaningless.

```python
import sympy as sp
x = sp.symbols('x', real=True)
expr = sp.sqrt(x**2)
print(sp.simplify(expr))  # Abs(x)
f = sp.Rational(1, 3)*x**3
assert sp.simplify(sp.diff(f, x) - x**2) == 0
```

Differentiating a proposed antiderivative checks it on the admitted intervals, but constants can differ across disconnected domains. Solving an equation may produce conditional solutions or omit branches if assumptions are insufficient. For a numerical root finder, the starting guess and convergence tolerance are additional algorithmic inputs; it is not a proof that every root was found.

Use a symbolic result as one stage of a reproducible argument: state hypotheses, derive or explain the relevant step, inspect special and singular cases, differentiate or substitute as a check, and compare with independent numerical samples. Sampling can falsify a claimed identity, but agreement at selected points cannot prove a universal statement.

</LessonSection>

For (x²−1)/(x−1), simplification gives x+1 only on x≠1. The simplified polynomial has value 2 at x=1, while the original expression is undefined there. Extending by continuity is a new explicitly defined function, not an automatic algebraic equivalence on all real inputs.
