<LessonSection id="story" title="Why this matters" layer="story">

Numerical linear algebra connects exact matrix theory with finite precision and noisy measurements. Fitting spectra and reconstructing images often produces ill-conditioned inverse problems.

</LessonSection>

<LessonSection id="intuition" title="Build the picture" layer="intuition">

The residual checks how closely a proposed solution satisfies the supplied equations. Conditioning checks how much the solution changes when the equations change slightly.

</LessonSection>

<LessonSection id="concept" title="State the model" layer="concept">

For Ax=b, backward error concerns a nearby problem solved exactly, while forward error concerns the distance from the intended solution. Conditioning relates them.

</LessonSection>

<LessonSection id="theory" title="Derive and qualify the result" layer="theory" fullOnly>

A matrix norm condition number is $\kappa(A)=\|A\|\|A^{-1}\|$ for invertible A in a consistent norm. In a perturbative regime, relative forward error can be amplified by κ times relative data or backward error. A tiny residual therefore need not mean a small parameter error for an ill-conditioned A. Singular matrices have no unique inverse; rectangular systems require rank and consistency analysis.

Solve a dense square system with a suitable factorization rather than explicitly computing A inverse times b. Pivoted LU handles many nonsingular systems; Cholesky uses symmetric positive-definite structure. Algorithm choice should reflect the matrix, not just which function name is familiar.

Least squares minimizes $\|Ax-b\|_2$. QR factorization or singular-value decomposition are often preferable to directly forming normal equations, because forming AᵀA squares the 2-norm condition number for full-column-rank A. In an SVD $A=U\Sigma V^T$, small singular values identify directions that data constrain weakly.

```python
import numpy as np
A = np.array([[1., 1.], [1., 1.000001]])
b = np.array([2., 2.000001])
x = np.linalg.solve(A, b)
print(x, np.linalg.norm(A @ x - b), np.linalg.cond(A))
```

Regularization stabilizes weak directions by introducing a penalty or prior, changing the inverse problem. Its strength must be justified and sensitivity reported. Scaling columns can improve numerical behaviour but does not invent missing physical information. Uncertainty propagation should include data covariance and model error rather than only a solver tolerance.


### Transfer derivation and failure case

For nonsingular $A$, perturbation bounds involve $\kappa_2(A)=\sigma_{max}/\sigma_{min}$. In full-column-rank least squares, singular values squared are the eigenvalues of $A^TA$, giving $\kappa_2(A^TA)=\kappa_2(A)^2$. QR or SVD methods avoid explicitly worsening conditioning through the normal equations. Regularization changes the inference problem by penalizing or suppressing selected directions; its parameter and scientific prior assumptions must be reported, not treated as a neutral numerical repair.

### Derivation and transfer

A small residual ||Ax−b|| need not imply a small solution error when A is ill-conditioned. For A=diag(1,ε), the 2-norm condition number is 1/ε when 0&lt;ε≤1. Perturbations along the small-singular-value direction are amplified.

The display isolates this conditioning example. It does not recommend explicitly forming an inverse: a factorization or suitable iterative solver is normally preferable. Conditioning is a problem property, while algorithmic stability describes how a computation responds to rounding.
