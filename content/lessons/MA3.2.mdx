<LessonSection id="story" title="Why the question matters" layer="story">

A matrix is a coordinate representation of a map. Confusing a basis change with a physical transformation makes operator formulas and units unreliable.

</LessonSection>

<LessonSection id="intuition" title="Build a mental model" layer="intuition">

Changing the measuring grid changes component labels. The underlying vector and the underlying map remain the same if all coordinate conversions are made consistently.

</LessonSection>

<LessonSection id="concept" title="Definitions and hypotheses" layer="concept">

A linear map T preserves linear combinations. Its kernel is the input subspace sent to zero, and its image is the subspace of attainable outputs.

</LessonSection>

<LessonSection id="theory" title="Derivation, proof and limitations" layer="theory" fullOnly>

Choose an input basis and an output basis. The jth column of the representing matrix is the output-coordinate vector of T applied to the jth input basis element. Matrix-vector multiplication follows by linearity. This construction explains why multiplication order follows composition: if S follows T, its matrix multiplies on the left.

For a map from an n-dimensional domain, rank–nullity states $\dim\ker T+\dim\operatorname{im}T=n$. To prove it, extend a kernel basis to a domain basis. Images of the added vectors span the image because the kernel terms vanish; their independence follows because any combination mapping to zero lies in the kernel. Thus their count is the rank.

For a square operator, injectivity, surjectivity and invertibility are equivalent in finite dimension. For an infinite-dimensional space, injectivity need not imply surjectivity: multiplication by x on polynomials is injective but misses the constant polynomial 1. The finite-dimensional qualification must not be silently dropped.

If old and new coordinates satisfy xold=S xnew, an operator matrix transforms as $A_{\rm new}=S^{-1}A_{\rm old}S$. This similarity rule changes both input and output coordinates of one operator on the same space. A map between different spaces uses separate conversion matrices. Similarity preserves the characteristic polynomial, eigenvalues and trace, but not every entry.

The dual space consists of linear functionals into the scalar field. A functional’s component transformation is chosen to keep its value on a vector invariant; it is not an independent physical scalar assigned to each axis. In Euclidean coordinates an inner product can identify vectors and functionals, but that identification introduces additional structure beyond a bare vector space.


### Derive, test and transfer

A linear map is defined independently of a basis, while a matrix records its coordinate action. If new domain coordinates use invertible P and new target coordinates use Q, the matrix transforms as Q inverse times A times P. For an endomorphism using the same basis change on both sides, the new matrix is P inverse A P.

Composition order matters because matrices act on the vector from the right. A shear followed by a rotation generally differs from rotation followed by shear. A change in entries does not mean the underlying map changed; conversely, using a coordinate-change formula on the wrong side gives a different physical transformation. Check the action on basis vectors to verify a convention.

</LessonSection>

<LessonSection id="worked" title="A worked argument" layer="worked" fullOnly>

The map T(x,y,z)=(x+y,z) from R³ to R² has kernel $\{(t,-t,0):t\in\mathbb R\}$, dimension 1. Its image is all R², dimension 2. Rank plus nullity is 3. It is surjective but not injective, consistent with its nonsquare domain and codomain.
