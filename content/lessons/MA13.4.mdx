<LessonSection id="concept" title="Definitions and hypotheses" layer="concept">

For a smooth normalized nondegenerate eigenstate family, Berry connection can be defined as A=i⟨u|du⟩, with curvature F=dA on a local parameter patch.

</LessonSection>

<LessonSection id="theory" title="Derivation, proof and limitations" layer="theory" fullOnly>

Under |u⟩→eⁱχ|u⟩, this convention gives A→A−dχ, so local connection values depend on phase choice. Curvature is unchanged. A closed-loop Berry phase $\gamma=\oint A$ is defined modulo 2π with the corresponding endpoint/patch accounting.

Adiabatic transport requires a gap and sufficiently slow parameter change in the applicable theorem, not merely a visually smooth path. Degeneracy can require a nonabelian subspace connection. Dynamic and geometric phases must be separated before comparing interference.

For a suitable complex line bundle over a closed oriented two-dimensional parameter manifold, the first Chern number is $C=(2\pi)^{-1}\int F$ with the chosen normalization. Integer quantization depends on global patch consistency and assumptions. Integrating an arbitrary open patch does not automatically give an integer.

For a spin-half eigenstate following a closed direction loop, the geometric phase is proportional to half the enclosed solid angle with sign tied to the branch/state convention. Topological robustness needs the protecting gap/symmetry conditions; a disorder or interaction change that closes the relevant gap can change classification. This introduction does not claim every phase factor is a topological invariant.


### Derivation and transfer

For a spin-half state adiabatically transported around a latitude on the Bloch sphere, a geometric phase is −Ω/2 modulo 2π for a stated eigenstate convention. The enclosed solid angle is Ω=2π(1−cosθ). Dynamical phase is a separate contribution.

The display follows that ideal loop and chosen sign convention. A Berry phase is not automatically an integer topological invariant; a Chern number instead integrates curvature over an appropriate closed parameter surface with normalization. Gap closing can invalidate an adiabatic argument.

</LessonSection>
