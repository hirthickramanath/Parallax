<LessonSection id="story" title="Why this matters" layer="story">

Numerical calculus is needed when a signal or model has no convenient analytic derivative or integral. Every algorithm balances approximation error against rounding, sampling and measurement noise.

</LessonSection>

<LessonSection id="intuition" title="Build the picture" layer="intuition">

A difference quotient subtracts nearby values. A smaller separation improves local approximation but amplifies errors in those values.

</LessonSection>

<LessonSection id="concept" title="State the model" layer="concept">

Numerical differentiation and quadrature approximate continuous operations with finite samples. Convergence order must be interpreted within smoothness and error assumptions.

</LessonSection>

<LessonSection id="theory" title="Derive and qualify the result" layer="theory" fullOnly>

For smooth f, Taylor expansion gives the forward difference $[f(x+h)-f(x)]/h=f'(x)+hf''(x)/2+O(h^2)$. The centred difference $[f(x+h)-f(x-h)]/(2h)$ has leading truncation error $h^2f^{(3)}(x)/6$. Its second-order claim needs the required derivatives and a sufficiently regular neighbourhood.

If each function value has rounding error of scale εF, differencing can introduce derivative error of order εF/h. Total error thus need not decrease monotonically with h. Noisy measurements create a similar amplification. The optimal step depends on function scales and precision; a single magic h is not universal.

For equally spaced nodes over [a,b], composite trapezoidal quadrature sums $h[f(a)/2+\sum_{j=1}^{n-1}f(a+jh)+f(b)/2]$. With a bounded second derivative it has global error of order h². Simpson's rule combines quadratic interpolation and has order h⁴ under adequate smoothness with an even number of equal subintervals. Discontinuities and unresolved oscillations invalidate simple error estimates.

```python
import numpy as np
x = np.linspace(0., 1., 101)
y = x*x
area = np.trapezoid(y, x)
print(area)  # approximately 1/3
```

A refinement check compares n and 2n intervals, while an analytic test establishes whether the implementation solves a known case. Neither alone proves correctness for every new integrand. Sampling cannot reconstruct features absent between observations without further assumptions; quoting extra decimal places does not create information.


### Transfer derivation and failure case

For a cubic, the correction is exactly $h^2$. Floating-point subtraction introduces an error scale proportional to machine precision divided by $h$, so truncation improvement cannot be extrapolated to arbitrarily small steps. Composite trapezoidal quadrature instead averages neighboring endpoint values across each panel; refining panels is a convergence test, not additional measured information. Discontinuities and noisy data require separate error models.

### Derivation and transfer

A centered derivative [f(x+h)−f(x−h)]/(2h) has O(h²) truncation error for sufficiently smooth f. For f=x³ at x=1 it equals 3+h² exactly, exposing the leading error. Floating-point cancellation eventually defeats the benefit of reducing h.

The browser evaluates this analytic benchmark without hiding the error sign. A convergence study needs several step sizes and a reference or asymptotic regime. Singularities, nonsmoothness and noisy data can invalidate the textbook power law.
