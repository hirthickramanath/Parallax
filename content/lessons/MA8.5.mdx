<LessonSection id="story" title="Why the question matters" layer="story">

Bayesian inference combines a data model with prior information and explicit parameter definitions. Posterior calculations are not independent of assumptions just because they are normalized probabilities.

</LessonSection>

<LessonSection id="intuition" title="Build a mental model" layer="intuition">

A prior assigns starting weight. The likelihood reweights it according to how each parameter value predicts the data; normalization turns that product into a distribution.

</LessonSection>

<LessonSection id="concept" title="Definitions and hypotheses" layer="concept">

For parameter θ, data D and model M, posterior density is proportional to likelihood times prior, with evidence obtained by integrating that product over the parameter domain.

</LessonSection>

<LessonSection id="theory" title="Derivation, proof and limitations" layer="theory" fullOnly>

Bayes' rule gives $p(\theta|D,M)=p(D|\theta,M)p(\theta|M)/p(D|M)$ with $p(D|M)=\int p(D|\theta,M)p(\theta|M)d\theta$. Likelihood is a function of θ for fixed data and need not integrate to one over θ. Its numerical density units depend on the data convention; posterior parameter density has parameter-space units.

For Bernoulli observations with s successes and f failures, a Beta(a,b) prior yields a Beta(a+s,b+f) posterior. Posterior mean is (a+s)/(a+b+s+f). This conjugate example shows how finite prior information affects a small sample while repeated independent data can dominate in appropriate identifiable models.

A credible interval contains specified posterior probability under the adopted prior and likelihood. It is not automatically a frequentist confidence interval with the same repeated-sampling coverage. Prior sensitivity, predictive checks and identifiability should be investigated rather than treating one interval as assumption-free.

Under a one-to-one parameter transformation φ=g(θ), density changes by a Jacobian. A prior uniform in θ is generally not uniform in φ. Improper priors can sometimes yield proper parameter posteriors, but model-evidence calculations need particularly careful normalization; arbitrary prior constants do not cancel safely in every model comparison.

Posterior predictive distributions average predictions over parameter uncertainty: $p(D_{\rm new}|D)=\int p(D_{\rm new}|\theta)p(\theta|D)d\theta$ under the specified model. They can reveal failures of fit, but using the same data twice for selection and checking needs interpretation. A highly concentrated posterior can be confidently wrong if the likelihood excludes important systematics.


### Derivation and transfer

For a Bernoulli parameter and a Beta(α,β) prior, s successes and f failures give Beta(α+s,β+f). The posterior mean is (α+s)/(α+β+s+f). This relies on the chosen likelihood and prior, not on a universal rule that data remove modeling choices.

The explorer fixes a uniform prior and a stated failure count while varying integer successes. A credible interval is a posterior probability statement conditional on that model; it need not have exact frequentist coverage for every parameter.

</LessonSection>
