<LessonSection id="story" title="Why this matters" layer="story">

Scientific Python turns models into reproducible calculations. Correct syntax is only the first check: a program must also represent the intended units, shape, axes and numerical precision.

</LessonSection>

<LessonSection id="intuition" title="Build the picture" layer="intuition">

An array is a block of values with a shape and a type. Operations may broadcast across dimensions rather than performing the pairing you intended.

</LessonSection>

<LessonSection id="concept" title="State the model" layer="concept">

Python names refer to objects; NumPy arrays support typed multidimensional data and vectorized operations. Reproducibility requires explicit inputs, dependencies and a record of choices.

</LessonSection>

<LessonSection id="theory" title="Derive and qualify the result" layer="theory" fullOnly>

Python floating-point values usually approximate real numbers with binary finite precision. Thus decimal quantities need not add exactly: compare computed results with a justified absolute and relative tolerance, not an unexplained equality or an arbitrary large tolerance. Catastrophic cancellation occurs when nearly equal large values are subtracted; algebraically equivalent expressions can have different numerical accuracy.

In NumPy a one-dimensional array of shape (n,) is not the same as a column of shape (n,1). Broadcasting aligns trailing dimensions, allowing equal sizes or a size of 1. Subtracting shapes (n,1) and (n,) creates an (n,n) result, not n residuals. Matrix product uses `@`; `*` is elementwise multiplication. Check shape and axis semantics at every scientific boundary. For compatible two-dimensional arrays, matrix multiplication computes $(AB)_{ij}=\sum_k A_{ik}B_{kj}$; elementwise multiplication computes $C_{ij}=A_{ij}B_{ij}$ when shapes match. These are different operations even for square arrays.

Slicing may return a view sharing the original data. Use an explicit copy when independent modification is required. Integer arrays can overflow; floating arrays can contain NaN or infinity. A sum along an axis removes that axis unless requested otherwise. Masks and missing-value handling change the sample used by an estimator and must be recorded.

```python
import numpy as np
x = np.array([0., 1., 2.])
y = 2*x + 1
assert x.shape == y.shape == (3,)
residual = y - (2*x + 1)
assert np.allclose(residual, 0, atol=1e-12, rtol=0)
```

A reproducible script separates model functions from file access and plotting, validates units and array shapes, and includes known analytic checks. A random seed helps reproduce one random sequence, but package versions and generator choice may also matter. Never treat the ability to run code without an exception as proof of a correct scientific result.


### Transfer derivation and failure case

Broadcasting compares shapes from the right; paired dimensions must be equal or one must be 1. For $(4,1)$ and $(1,5)$ the result is $(4,5)$, not $(4,1,5)$. A reduction with axis=0 combines the rows and removes that axis unless keepdims is requested. Basic slicing generally returns a view, so assignment through it can mutate the parent; an explicit copy separates storage. Shape compatibility is not evidence that a calculation represents the intended physical pairing: label which axes denote samples, coordinates and parameters before broadcasting scientific arrays.

</LessonSection>
