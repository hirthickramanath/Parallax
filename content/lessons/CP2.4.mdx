<LessonSection id="story" title="Why the question matters" layer="story">

Scientific machine learning must control leakage, selection and extrapolation before a predictive score supports any scientific interpretation.

</LessonSection>

<LessonSection id="concept" title="Definitions and hypotheses" layer="concept">

Supervised learning fits a mapping from features to labels using a specified loss and validation design. Generalization is evaluated on observations not used in fitting or model selection.

</LessonSection>

<LessonSection id="theory" title="Derivation, proof and limitations" layer="theory" fullOnly>

Separate training, validation and final test roles. Fit preprocessing, imputation and feature selection only on training data within each fold. Leakage occurs when label information or held-out distribution statistics enter training. Grouped observations from the same source, simulation run or instrument may need group-based splits; random row splitting can put near-duplicates on both sides.

For a regression residual r=y−ŷ, mean squared error is $N^{-1}\sum r_i^2$. Its units are squared target units and sensitivity to outliers differs from absolute error. A metric must match the scientific task and uncertainty model. In an imbalanced classifier, high accuracy can result from predicting the majority class; inspect class-conditional performance and relevant false-positive costs.

Regularization and model complexity affect bias and variance, but hyperparameters selected on a validation set make that set part of the selection process. A final untouched test or nested validation is needed for the corresponding unbiased assessment goal. Time evolution, survey selection and domain shifts can make even a properly held-out historical test unrepresentative of deployment.

A calibrated predictive probability is not automatically a physical posterior over causal parameters. Distinguish measurement noise, model uncertainty and out-of-distribution ignorance. Compare simple baselines, inspect residuals against physical covariates and test conservation/symmetry constraints where justified. Feature importance or correlation does not establish causation. Keep synthetic training data labelled and document simulator mismatch before claiming performance on real observations.


### Derivation and transfer

A scientific model must be evaluated on data that did not leak into training or preprocessing. If scaling or feature selection sees the test set, reported error can be optimistic even when the final regressor never directly fits test labels. Splits must respect shared objects, time and spatial dependence.

The display computes a squared prediction error for a one-point toy. It does not train a model or establish generalization. Compare against a baseline and examine calibration, out-of-distribution behavior and physical constraints before treating a small held-out error as scientific discovery.

</LessonSection>
