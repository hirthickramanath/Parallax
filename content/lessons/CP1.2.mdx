<LessonSection id="story" title="Why this matters" layer="story">

Plots are scientific arguments, not decorations. Axis transformations, binning, uncertainty and selection determine what a reader can reasonably infer from a figure.

</LessonSection>

<LessonSection id="intuition" title="Build the picture" layer="intuition">

A graph maps values into positions. On a logarithmic axis equal distances represent ratios; on a linear axis they represent differences.

</LessonSection>

<LessonSection id="concept" title="State the model" layer="concept">

A reproducible figure identifies variables, units, scales, sampling and uncertainty. Visual appearance alone is not a fitted model or a hypothesis test.

</LessonSection>

<LessonSection id="theory" title="Derive and qualify the result" layer="theory" fullOnly>

Choose a plot matched to the data: a scatter plot shows paired measurements; a line implies an order or connecting model; a histogram depends on bin choices; an image has a spatial coordinate system and colour scale. Connecting unordered samples can suggest a trajectory that was never observed.

For a power law $y=Ax^p$ with positive x,y, logs give $\ln y=\ln A+p\ln x$. A straight log–log line is compatible with a power law but does not establish one uniquely. Additive errors transform nonuniformly under logs; least squares in log space and original space minimize different residuals. Zero and negative values cannot simply be dropped without explaining the selection.

Error bars must state what they represent: measurement standard deviation, standard error or an interval from a specified inference method. Correlated errors are not fully described by independent bars. Use dimensionally meaningful labels and preserve relative geometric scales when angle or shape is the intended observable.

```python
import numpy as np
import matplotlib.pyplot as plt
x = np.array([1., 2., 3.])
y = x*x
fig, ax = plt.subplots()
ax.plot(x, y, 'o', label='synthetic samples')
ax.set(xlabel='x (dimensionless)', ylabel='y (dimensionless)')
ax.legend()
fig.savefig('square-samples.png', dpi=150, bbox_inches='tight')
```

Store the script and source data alongside a figure. Identify smoothing, normalization, excluded points and a colour scale. Avoid a colour map that makes an arbitrary midpoint appear to be a physical threshold. Captions should distinguish a generated model from independent measurements and state what comparison could refute the proposed interpretation.

</LessonSection>
